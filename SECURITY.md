# Security

If you find a security issue, please report it privately to the maintainers. Do not open a public issue.

**Confidential contact:** security@example.com

## Scope

This project is a local-first AI codebase navigator. Security-relevant areas include:

- API key validation (POST /api/v1/auth/validate)
- Project sync over the network
- Authentication (GitHub OAuth via Auth.js)
- Payment handling (Chapa)

## Reporting

Please do not attempt to exploit a vulnerability publicly. Email the confidential contact and we will acknowledge receipt and work with you to resolve the issue.
